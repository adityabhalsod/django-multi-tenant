# Security policy

## Supported versions

Security fixes are made on the `main` branch.

## Reporting a vulnerability

**Please do not open a public issue.** Use GitHub's
[private vulnerability reporting](../../security/advisories/new) instead. Include steps to
reproduce, the impact (especially any cross-tenant data access) and a suggested fix if you
have one.

You will get an acknowledgement within a few days. Once a fix is released you will be
credited in the release notes unless you prefer otherwise.

The isolation model and its known limits are documented in
[docs/13-security.md](docs/13-security.md).
